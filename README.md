# Blogging Web

A simple blogging platform where users can post their articles and view others' posts. Built using HTML, CSS, and Node.js.

Features

Create and Publish Blog Posts: Users can write, format, and publish their blog posts seamlessly.

View Other Users' Posts: Read articles from different users and gain insights from their content.

Responsive UI: A clean and modern design that adapts to different screen sizes.

User Authentication: Secure login and registration system to manage user profiles.

Commenting System: Users can engage with posts by leaving comments.

Search Functionality: Easily find posts by searching for keywords or categories.

Technologies Used

Frontend: HTML, CSS

Backend: Node.js (Express.js framework for handling server-side logic)

Database: (MongoDB)

Authentication: (JWT)
